# Shortcuts

## File

| | |
|---|---|
| Ctrl+N | New tab |
| Ctrl+O | Open (multi-select → tabs) |
| Ctrl+S | Save |
| Ctrl+W | Close tab |
| **Esc Esc Esc** (≤ 500 ms apart) | **Exit** (save prompts) |
| Alt+F4 / File → Exit | Exit |

A second `jptxt.exe file` does not start another process. The file opens in the running window.

## Edit

| | |
|---|---|
| Ctrl+Z / Y | Undo / Redo |
| Ctrl+X / C / V / A | Cut / Copy / Paste / Select all |
| Tab / Shift+Tab | Indent / unindent (block if selection spans lines) |
| Insert | Insert / overwrite |

## Search / view

| | |
|---|---|
| Ctrl+F | Find (regex) |
| F3 / Shift+F3 | Find next / previous |
| Ctrl+H | Replace |
| Ctrl+G | Go to line |
| Ctrl+Shift+H | Hex lister |
| Ctrl+Tab / Ctrl+Shift+Tab | Next / previous tab |
| Ctrl++ / − / 0 | Font size |
| Middle-click tab / tab × | Close tab |

Drop files on the window to open them as tabs.
