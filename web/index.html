notepad

jptxt

A super-fast native notepad. Tabs, syntax highlight, regex search, hex lister for binaries. No Electron, no sidebar, no scripting. One process.

Windows

irm https://whatamieatingtoday.com/app/jptxt/install.ps1 | iex

PowerShell. Installs to %LOCALAPPDATA%\Programs\jptxt and adds it to your user PATH.

macOS / Linux

curl -fsSL https://whatamieatingtoday.com/app/jptxt/install.sh | bash

Installs to ~/.local/bin. Linux needs libx11-6 (sudo apt install libx11-6).

Or grab a binary

Windows x64 macOS Apple Silicon Linux x64

What you get

  • Opens 100 MB+ text files (mmap, ~30–70 ms)
  • Single instance — a second launch adds a tab
  • Triple-Esc closes
  • ~200–400 KB, no extra runtime
